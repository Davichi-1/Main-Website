# David Chidera Tobias — portfolio

A static site: `index.html` plus an `assets/` folder. No build step.

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. On vercel.com choose Add New > Project and import the repository.
3. Framework Preset: Other. Leave the build and output settings empty, then Deploy.
Every later push to GitHub redeploys the site automatically.

## Edit
- Approved reviews go in the `REVIEWS` array near the bottom of `index.html`, as `{name, role, rating, text}`.
- Images are in `assets/img`, videos in `assets/video`, the CV is `assets/David-Chidera-Tobias-CV.pdf`.
